# SQL Certificate Course (Break Into Tech)

This section contains exercises and projects completed as part of the Break Into Tech SQL curriculum.

These projects cover foundational SQL concepts including querying, filtering, aggregation, joins, subqueries, window functions, and data transformation techniques.

## Topics Covered

- SELECT statements
- Filtering and sorting
- Aggregations
- Joins
- Common table expressions (CTEs)
- Subqueries
- Window functions
- Data cleaning
- Analytical SQL patterns

## Purpose

These files represent structured coursework used to build core SQL skills and provide examples of foundational query techniques that were later applied in professional analytics projects.
