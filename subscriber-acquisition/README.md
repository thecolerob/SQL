# Subscriber Acquisition

Projects focused on understanding how content, campaigns, and promotional channels drive new subscriptions.

## Topics Covered
- First-watch attribution
- Program-driven subscriber acquisition
- Episode release impact analysis
- Influencer and affiliate acquisition

## Example Questions Answered
- Which programs drive the most new subscribers?
- How much incremental acquisition is generated by each episode release?
- Which acquisition channels produce the highest subscriber volume?
- How does content performance influence subscription growth?
